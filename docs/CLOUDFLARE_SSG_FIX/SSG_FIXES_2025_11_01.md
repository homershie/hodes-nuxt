## Issue 1: Article Route 404 Error

### Problem
- After `npm run generate`, article directory not created
- Error: `queryContent is not defined`
- Article pages showing 404 during prerendering

### Root Cause
Incorrect Nuxt Content API usage. Project uses single content collection, should use `queryCollection` instead of `queryContent`

### Solution

Modified `app/pages/article/[id].vue`:

```typescript
// BEFORE (Wrong)
const { data: currentArticle } = await useAsyncData(
  `article-${articleId}`,
  () => queryContent(`/articles/${articleId}`).findOne(),
  { server: true, lazy: false }
)

// AFTER (Correct)
const { data: allArticles } = await useAsyncData(
  'articles-list',
  () => queryCollection('content').all(),
  { server: true, lazy: false }
)

const currentArticle = computed(() => {
  if (!allArticles.value) return null
  return allArticles.value.find(item => {
    const itemId = item.stem ? item.stem.replace(/^articles\//, '') : item.id
    return itemId === articleId
  })
})
```

### Additional Changes

1. Handle meta field parsing (may be JSON string)
2. Fix 404 handling (server-side only check)
3. Set `autoSubfolderIndex: true` in nuxt.config.ts
